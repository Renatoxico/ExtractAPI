Ao utilizar o Extract, você concorda com os termos descritos neste documento. Leia com atenção antes de usar o serviço.

1. Sobre o Serviço

O Extract é um serviço web de análise de extratos bancários em PDF. O sistema extrai transações, gera relatórios para uso pessoal e utiliza inteligência artificial como etapa complementar de categorização.

Quando uma categoria não está disponível, o relatório utiliza a categoria padrão “Outros / Transferências”. A extração de valores e transações permanece disponível independentemente do resultado da categorização.

2. Elegibilidade

Para usar o Extract, você deve:

  • Ter ao menos 18 anos de idade
  • Possuir uma conta Google válida para autenticação
  • Fornecer apenas arquivos que você esteja autorizado a processar

3. Acesso e Disponibilidade

O acesso depende da disponibilidade da aplicação, do banco de dados e dos provedores externos utilizados para autenticação e processamento. Funcionalidades, limites e condições de acesso podem ser alterados conforme a evolução do serviço.

4. Uso dos Dados

Os arquivos PDF enviados são processados para extrair as transações e gerar o relatório solicitado. O arquivo original não é mantido após o processamento; as transações extraídas, categorias e totais são armazenados no banco de dados associados à conta autenticada para permitir a consulta do relatório.

Para categorização, o sistema pode enviar descrições de transações ao serviço Google Gemini. Valores, datas, o arquivo PDF completo e identificadores da conta não fazem parte dessa solicitação de categorização.

A autenticação utiliza Firebase Authentication, do Google. Um provedor SMTP processa mensagens operacionais destinadas aos administradores, que podem conter informações necessárias para investigar falhas de categorização. Esses serviços atuam como provedores técnicos do Extract.

Utilizamos dados da conta, como e-mail e identificador de usuário, para autenticação, controle de acesso, associação e suporte dos relatórios. Não vendemos dados pessoais ou financeiros.

  • Enviar arquivos que não sejam extratos bancários pessoais
  • Utilizar o serviço de forma automatizada sem autorização prévia
