Extract API

Authenticated API for extracting expense reports from PDF files.

POST/v2/extract

Accepts one to six PDF files in the multipart field file and creates a report.

GET/v2/extract/summary/{reportId}

Returns an owner-scoped report using the canonical camelCase contract.

GET/v2/extract/export/{reportId}

Exports expenseId,expenseName,category,amount,date,reportId as CSV.

POST/extract/raw-text/

Diagnostic utility that extracts raw text without creating a report.

All endpoints require a Firebase bearer token. Report lookup and export return the same 404 REPORT_NOT_FOUND for missing reports and reports owned by another user.
