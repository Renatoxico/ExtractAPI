# Synthetic Phase 0 corpus

All content is invented. These short, text-layer layouts imitate common public
card-statement tables; they are not real statements or certified bank adapters.
No customer names, tax identifiers or card/account numbers are included.
Each expected.json retains the complete source text and ordered golden rows.
Tests also render these strings into tiny PDFs in memory and parse them again.
Only slash dates, leading minus signs and one BRL amount column are covered.
Foreign currency columns, multiline rows, positive-credit direction, trailing
minus/parentheses, and future-installment sections need later layout adapters.
